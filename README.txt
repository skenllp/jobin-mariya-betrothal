Jobin & Maria — Wedding Invitation Website
==========================================

HOW TO USE
----------
1. Keep index.html and the "assets" folder together.
2. Double-click index.html to preview in any browser.
3. To publish, upload the whole folder to any static host
   (Netlify, Vercel, GitHub Pages, ...). No build step needed.

ASSETS
------
assets/couple.jpeg   PLACEHOLDER (floral crop). Replace with the couple's
                     photo, same filename, portrait 3:4 works best.
assets/hero.jpg      Decorative floral hero background (unchanged).
assets/soft-bg.jpg   Closing-section background (unchanged).
assets/og-image.jpg  1200x630 link-preview image (regenerated with names/date).
assets/music.mp3     Wedding song (supplied by the couple); loops continuously. Tap the note
                     icon (bottom-right) to play/pause; never autoplays.
                     Swap the file (same name) to change the song.

NOTES
-----
- All names, dates, venues and addresses are plain HTML text in index.html.
- Map buttons open Google Maps searches for the two churches; replace the
  hrefs with exact map links if you have them.
- Open Graph URL tags were removed; after deploying, add og:url and make
  og:image an absolute URL for best WhatsApp previews.
- Contact number in the closing section: 9495393315.
